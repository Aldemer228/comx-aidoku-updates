# Com-X for Aidoku

Публичный каталог обновлений расширения **Com-X Editorial** для приложения Aidoku.

**Постоянный адрес списка источников:**

`https://raw.githubusercontent.com/Aldemer228/comx-aidoku-updates/main/index.min.json`

Добавление: Aidoku → Настройки → Списки источников → добавить адрес → обновить список.

## Публикация проверенной версии

1. Собрать и проверить новый файл расширения в приватном репозитории.
2. Из готового GitHub Actions-артефакта извлечь внутренний `aidoku-comx-feed.zip`.
3. Назвать извлечённый архив по версии, например `comx-feed-v18.zip`, и загрузить его через **Add file → Upload files** в этот публичный репозиторий.
4. GitHub Actions проверяет номер версии, идентификатор `ru.comx`, установочный файл и перечень файлов. После этого публикует `index.min.json`, иконку и `.aix`.
5. В Aidoku обновить уже добавленный список источников и установить новую версию. Удалять старый источник не требуется.

Файл с номером версии не нужно перезаписывать: при следующем выпуске достаточно загрузить `comx-feed-v19.zip`. Публикация версии ниже уже опубликованной блокируется.

Исходный код и секреты не публикуются здесь. Авторизация на Com-X остаётся локальной в Aidoku.

**Статус:** публичный список первоначально содержал v11; v18 проверена пользователем и подготовлена для публикации.
