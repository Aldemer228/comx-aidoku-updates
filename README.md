# Com-X for Aidoku

Публичный каталог обновлений расширения **Com-X Editorial** для приложения Aidoku.

**Адрес списка источников:**

`https://raw.githubusercontent.com/Aldemer228/comx-aidoku-updates/main/index.min.json`

Добавление: Aidoku → Настройки → Списки источников → добавить адрес → обновить список.

Расширение использует Com-X (https://com-x.life/). Этот репозиторий содержит только готовые сборки `.aix`, иконку и каталог версий. Исходный код хранится отдельно в приватном репозитории.

**Статус:** подготовка первой публикации v11.
